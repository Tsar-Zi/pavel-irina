# Свадебный сайт-приглашение: Павел и Ирина

Обычный статический сайт (HTML + CSS + JS), без сборки и без установки программ.
Шрифты лежат внутри проекта (`fonts/`), внешние сервисы нужны только для анкеты.

## Запуск на компьютере
Самый простой способ: дважды щёлкнуть `index.html`.
Или из папки проекта: `python3 -m http.server 8000` и открыть http://localhost:8000.

## Что и где менять
| Что | Где |
|---|---|
| Имена, дата, время, адрес, тексты, цитата, ссылка на Telegram, цвета dress code, вопросы анкеты | `js/config.js` (всё подписано) |
| Цвета сайта (три основных) | `css/style.css`, самый первый блок `:root` |
| Фотографии | папка `images/`: заменить файл с тем же именем |
| Положение фото в кадре (если обрезается лицо) | `js/config.js`, `photoPosition` |

Фотографии:
- `hero.jpg`: обложка (на ней имена, дата и стих)
- `photo-2.jpg`: большое фото после календаря
- `location.jpg`: арка в блоке «Локация»
- `dresscode.jpg`: арка в блоке Dress code (букет)
- `countdown.jpg`: фото с таймером (таймер стоит по центру, между фигурами)

Лучше вертикальные кадры 3:4, шириной 1200–1500 px, до 400 КБ.

### Время свадьбы
В `config.js` указано `time: "11:00"`: оно показывается рядом с адресом, по нему считает таймер и ставится время в календаре гостя. Если время поменяется, правьте только это поле. Часовой пояс задан в `timezone` (Волгодонск: `+03:00`).

### Шрифты
Заголовки: Anastasia Script, обычный текст: Cormorant Garamond (лежит в `fonts/`).
Anastasia Script платный и в проект не включён, поэтому пока заголовки набраны похожим рукописным шрифтом Great Vibes.
Чтобы подключить настоящий: положите файл в `fonts/` как `anastasia-script.woff2` (или `.ttf`) и в `css/style.css`, в блоке `@font-face { font-family: "Anastasia Script"` уберите `/*` и `*/` вокруг строк с `url(...)`. Больше ничего менять не нужно.

### Видео в конце
На нём лежит подпись «Мы ждём вас…» (текст в `finalTitle`), она исчезает при воспроизведении. Файл `video/wedding.mp4` (постер `video/poster.jpg`). Чтобы заменить, положите другой mp4 H.264 с тем же именем (лучше до 10 МБ, чтобы быстро грузился с телефона).

### Цветы на фоне
`images/flora.png` (белые) лежит фоном на шалфейных блоках, `images/flora-sage.png` (цвета шалфея) на светлых. Рядом с фото «идут спиной» стоят отдельные веточки `flora-l-sage.png` и `flora-r-sage.png`.

### Вступительное видео (конверт)
`video/intro.mp4`: при открытии сайта сначала играет оно, конверт раскрывается и открывает фото с обложки, потом плавно появляется сайт. Есть кнопка «Пропустить»; если браузер не разрешает автозапуск, появится «Открыть приглашение». Фото вмонтировано в видео (`images/hero.jpg`): если замените обложку, видео нужно пересобрать (напишите мне).
Отключить вступление совсем: в `index.html` удалите блок `<div class="intro" …>` в начале `<body>`.

### Музыка
Положите mp3 в папку `audio/`, в `config.js` укажите `music: "audio/song.mp3"`. Появится кнопка Play/Pause. Музыка сама не включается.

## Анкета гостя: подключение (обязательно)
Пока `rsvp.endpoint` пустой, форма **ничего не отправляет** и честно пишет об этом. Подключение через Google Таблицу, примерно 5 минут:

1. Создайте новую Google Таблицу.
2. Меню **Расширения → Apps Script**, удалите всё в редакторе и вставьте содержимое файла `apps-script/Code.gs`, сохраните.
3. **Развернуть → Новое развёртывание → тип «Веб-приложение»**. Выполнять от имени: **Я**. Доступ: **Все**. Нажмите «Развернуть» и подтвердите доступ.
4. Скопируйте выданный адрес (оканчивается на `/exec`) и вставьте в `js/config.js`: `endpoint: "https://script.google.com/macros/s/…/exec"`.
5. Отправьте тестовый ответ с сайта. Строка должна появиться в таблице.

Если после изменения скрипта ответы не доходят, создайте новое развёртывание (версию) и обновите адрес.
Вопросы анкеты меняются в `config.js`, `rsvp.questions`. Столбцы таблицы создаются по первому ответу, поэтому после смены вопросов начните с чистого листа.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub, загрузите в него **содержимое этой папки** (чтобы `index.html` лежал в корне).
2. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту-две сайт откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Все пути в проекте относительные, поэтому ничего настраивать под имя репозитория не нужно.
Адрес Pages можно открыть и с телефона, и отправлять гостям.
